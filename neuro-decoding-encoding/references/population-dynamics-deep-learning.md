# Population Dynamics via Deep Learning

Modern latent-variable methods for population-level neural data — distinct from both classical
decoding (predicting a label) and classical simulation (`computational-modeling`'s biophysical
models). These methods learn a low-dimensional trajectory or embedding that captures how a neural
population's state evolves, rather than mapping population activity directly to a behavioral label.

## When this is the right tool, vs. plain decoding or PCA

| | Basic decoding (this skill's core usage) | PCA/plain dimensionality reduction | Population dynamics (this reference) |
|---|---|---|---|
| Question | Does this population encode variable Y? | What are the dominant linear axes of variance? | What are the (possibly nonlinear) dynamics governing population state over time? |
| Output | A classifier/regressor and its accuracy | A set of orthogonal linear components | A learned latent trajectory, often nonlinear, often trial-consistent |
| Typical use | "Is stimulus identity decodable from this region?" | Quick exploratory visualization | "What's the shared low-dimensional structure across trials/sessions, even without labeled conditions?" |

## CEBRA — contrastive learning for consistent embeddings

CEBRA learns embeddings that are consistent across recording sessions or subjects, using either
behavioral labels or the timing structure of the data itself as the contrastive signal:

```python
import cebra

model = cebra.CEBRA(
    model_architecture="offset10-model",
    batch_size=512, output_dimension=8, max_iterations=5000,
)
model.fit(neural_data, behavior_labels)  # behavior_labels optional — CEBRA-Time uses timing alone

embedding = model.transform(neural_data)
```

## Validation & Pitfalls

Canonical references: Pandarinath et al. (2018), "Inferring single-trial neural population dynamics
using sequential auto-encoders," *Nature Methods*, for LFADS; Schneider, Lee & Mathis (2023),
"Learnable latent embeddings for joint behavioural and neural analysis," *Nature*, for CEBRA.

- **These methods can find structure in noise if not validated carefully.** A learned embedding that
  looks like a clean, interpretable trajectory is not automatically evidence the underlying dynamics
  are real — check that the embedding is consistent across independent train/test splits of trials,
  and ideally across independent recording sessions, not just visually compelling on the data it was
  fit to.
- **CEBRA's embeddings depend heavily on the choice of contrastive signal (behavior labels vs.
  time).** CEBRA-Behavior and CEBRA-Time answer different questions and can produce different
  embeddings from the same data — state which was used, and don't treat them as interchangeable
  validations of the same claim.
- **LFADS-style smoothing can suppress genuine single-trial variability**, since the model is
  explicitly regularized toward a low-dimensional, smooth trajectory. A denoised firing-rate estimate
  from LFADS is not a substitute for reporting raw single-trial variability when that variability
  itself is the scientific question.
- **These are data-hungry methods relative to classical approaches** — small sessions (few trials,
  few neurons) that would support a simple decoder may not have enough data to fit a deep
  latent-dynamics model reliably; check convergence and out-of-sample consistency rather than
  assuming the fit is meaningful because training loss decreased.
- **A compelling low-dimensional visualization is not itself a statistical result.** Any claim built
  on a learned embedding (e.g. "condition A and B are separable in latent space") still needs a
  proper statistical test in that space, with the same cross-validation discipline as the rest of
  this skill — not just visual separation in a 2D/3D plot.
